# 📍 Электронный гид по достопримечательностям

## 📖 Описание проекта
**Электронный гид** — это консольное приложение на Python, которое позволяет управлять информацией о достопримечательностях, создавать маршруты и просматривать карту с посещенными местами.

## 🔧 Функциональность
- Добавление достопримечательностей
- Просмотр информации о местах
- Добавление фото и отзывов
- Создание маршрутов
- Просмотр карты с отмеченными достопримечательностями

## 🔨 Использование
Запустить приложение можно с помощью команды:
```sh
python main.py
```
После запуска появится меню с вариантами действий.

## 🧪 Тестирование
В проекте реализованы юнит-тесты, которые проверяют основные функции приложения.
Запуск тестов выполняется командой:
```sh
python -m unittest test_guide.py
```
