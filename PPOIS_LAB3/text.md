# Отчет по проекту "Crimsonland"

## Описание проекта
Проект "Crimsonland" представляет собой игру в жанре top-down шутера, где игрок сражается с волнами врагов, используя различное оружие и специальные способности (перки). Игра разработана с использованием библиотеки Pygame и включает в себя несколько модулей, отвечающих за различные аспекты игрового процесса.

## Основные модули

### 1. `files.py`
- **Описание**: Модуль отвечает за загрузку данных из JSON-файлов, таких как характеристики врагов, игрока и оружия.
- **Функционал**:
  - Загрузка данных о волнах врагов из `waves.json`.
  - Загрузка характеристик врагов из `enemy.json`.
  - Загрузка характеристик игрока из `player.json`.
  - Загрузка характеристик оружия из `weapon.json`.

### 2. `enemy.py`
- **Описание**: Модуль содержит классы для создания и управления врагами.
- **Классы**:
  - `Enemy`: Базовый класс для врагов, включающий анимацию, движение, атаку и обработку смерти.
  - `BasicEnemy`: Класс для базового врага, наследуется от `Enemy`.
- **Функционал**:
  - Движение врагов в направлении игрока.
  - Обработка попаданий пуль и анимация смерти.
  - Атака игрока с нанесением урона.

### 3. `bullet.py`
- **Описание**: Модуль отвечает за создание и управление пулями.
- **Класс**:
  - `Bullet`: Класс для пуль, выпускаемых игроком или врагами.
- **Функционал**:
  - Движение пули в заданном направлении.
  - Удаление пули при выходе за пределы карты.

### 4. `sounds.py`
- **Описание**: Модуль отвечает за загрузку и воспроизведение звуковых эффектов.
- **Функционал**:
  - Загрузка звуков для врагов, оружия, попаданий и других событий.
  - Воспроизведение звуков в зависимости от игровых событий.

### 5. `perk.py`
- **Описание**: Модуль отвечает за реализацию специальных способностей (перков).
- **Класс**:
  - `Perk`: Класс для активации перка, который создает множество пуль, летящих во всех направлениях.
- **Функционал**:
  - Активация перка при накоплении достаточного урона.
  - Создание пуль под разными углами.

### 6. `loading_images.py`
- **Описание**: Модуль отвечает за загрузку и масштабирование изображений.
- **Функционал**:
  - Загрузка изображений для фона, игрока, оружия, врагов и других элементов.
  - Масштабирование изображений до нужного размера.

### 7. `weapon.py`
- **Описание**: Модуль содержит классы для создания и управления оружием.
- **Классы**:
  - `Weapon`: Базовый класс для оружия, включающий перезарядку, стрельбу и анимацию.
  - `Pistol`, `Rifle`, `Shotgun`: Классы для конкретных типов оружия, наследуются от `Weapon`.
- **Функционал**:
  - Стрельба с учетом задержки между выстрелами.
  - Перезарядка оружия.
  - Анимация поворота оружия.

### 8. `player.py`
- **Описание**: Модуль содержит класс для управления игроком.
- **Класс**:
  - `Player`: Класс для игрока, включающий движение, стрельбу, получение урона и активацию перков.
- **Функционал**:
  - Движение игрока по карте.
  - Стрельба из текущего оружия.
  - Получение урона от врагов и активация перка.

### 9. `temporaries.py`
- **Описание**: Модуль содержит класс для управления глобальным состоянием игры.
- **Класс**:
  - `GameState`: Класс для хранения состояния игры, включая параметры экрана, камеры, игровых объектов и таймеров.
- **Функционал**:
  - Управление состоянием игры (загрузка, меню, игра, поражение, победа).
  - Хранение данных о игроке, врагах, пулях и оружии.

### 10. `test.py`
- **Описание**: Основной модуль игры, содержащий главный игровой цикл.
- **Функционал**:
  - Управление переходами между состояниями игры (загрузка, меню, игра, поражение, победа).
  - Обработка событий (нажатия клавиш, мыши).
  - Отрисовка игровых объектов и интерфейса.
  - Управление волнами врагов и таймерами.

## Заключение
Проект "Crimsonland" представляет собой полноценную игру с множеством функциональных модулей, каждый из которых отвечает за определенный аспект игрового процесса. Игра включает в себя управление игроком, стрельбу, волны врагов, специальные способности и звуковые эффекты. Все модули взаимодействуют между собой через глобальное состояние игры, что обеспечивает гибкость и масштабируемость проекта.
