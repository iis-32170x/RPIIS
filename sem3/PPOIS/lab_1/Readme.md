## Вариант 2: Модель магазина электротехники

**Предметная область**: взаимодействие покупателей с магазином электротехники.

**Важные сущности**: магазин, покупатель, товар, касса, консультант, каталог, акции, гарантия.

**Операции**: операция поиска товара в каталоге, операция консультации с продавцом, операция оформления покупки, операция возврата товара, операция участия в акциях.

## Описание программы

1. Класс **Guarantee**

Поля:
* `term` - гарантия товара

Методы: конструктор и геттер

  ```python
  class Guarantee:
    def __init__(self, term) -> None:
        self.__term = term

    def get_term(self) -> float:
        return self.__term  
  ```

2. Класс **Product**
   
Поля:
* `name` - название
* `price` - цена
* `guarantee` - гарантия

Методы: получить цену, название, гарантию, вывести информацию о товаре

3. Класс **Customer**

Поля:
* `name` - имя
* `money` - баланс
* `products` - список имеющихся товаров магазина

Методы: вывести информацию о покупателе, добавить\убрать товар, получить имя, поменять/получить список товаров, установить баланс

4. Класс **Consultant**

Поля:
   * `questions` - словарь вопросов и ответов
     
 Методы: вывод списка вопросов, выбор вопроса и получение на него ответа

 5. Класс **Catalog**

Поля:
* `products` - список товаров
   
Методы: добавить\удалить продукт, просмотр каталога, найти каталог, получить каталог

6. Класс **Cashbox**
   
   Методы: купить товар, вернуть товар

7. Класс **Share**

   Метод: лотерея

8. Класс **Electroshop**

Поля: 

* `customers` - список покупателей

 Методы: просмотр списка покупателей, добавить\удалить покупателя, получить покупателя
